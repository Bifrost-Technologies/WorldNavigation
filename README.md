# World Navigation

Forever WoW **1.60.1 / Interface 16001**. Open `/wnav`.

World Navigation supplies route planning to Flight Path Finder using native-georeferenced map-image weight grids. Roads are preferred over ordinary traversable ground, and remembered no-pass and hazard data can affect route cost. Cross-zone routing combines aligned image coverage. Map artwork is a 2D estimate: painted hills do not provide measured heights or collision. Dungeon image templates require a matching native map/floor binding before routing.

Source-image provenance: map grids were derived from Classic map artwork at https://wow.zamimg.com/images/wow/classic/maps/enus/original/. Source JPEGs are not bundled. No heightmap or collision mesh is claimed. No gameplay tests were run for this packaging pass.
